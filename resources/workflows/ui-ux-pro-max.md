# UI/UX Pro Max Workflow

## Purpose
Implement high-quality UI/UX following design system guidelines and best practices.

## Steps

1. **Design Analysis**
   - Review design specifications
   - Identify component requirements
   - Check design system compliance
   - Plan responsive breakpoints

2. **Component Implementation**
   - Build atomic components first
   - Compose into molecules/organisms
   - Implement states (hover, focus, disabled, loading)
   - Add accessibility attributes

3. **Integration**
   - Connect to data/state
   - Implement forms with validation
   - Handle loading/error/empty states
   - Keyboard navigation

4. **Quality Assurance**
   - Visual regression testing
   - Accessibility audit (axe, manual)
   - Cross-browser testing
   - Mobile device testing
   - Performance profiling

5. **Documentation**
   - Component API documentation
   - Usage examples
   - Design token references
   - Changelog

## Outputs
- Implemented UI components
- Integrated screens/pages
- Test coverage
- Documentation
- Performance benchmarks
