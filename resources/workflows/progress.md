# Progress Workflow

## Purpose
Track and communicate project progress effectively.

## Daily Standup Format

### Yesterday
- Completed tasks
- Blockers encountered
- Decisions made

### Today
- Planned tasks
- Expected blockers
- Collaboration needs

### Metrics
- Story points completed
- Test coverage delta
- Deploy frequency
- Bug count

## Sprint Tracking

### Sprint Planning
- Capacity calculation
- Story selection
- Task breakdown
- Definition of done

### Mid-Sprint
- Burndown review
- Scope adjustment
- Blocker escalation
- Retro action items

### Sprint Review
- Demo completed work
- Stakeholder feedback
- Metrics review
- Process improvements

## Progress Reporting

### Weekly Summary
- Completed features
- In-progress work
- Risks and blockers
- Upcoming priorities

### Monthly Report
- Velocity trends
- Quality metrics
- Technical debt
- Team health

## Tools
- Project board (GitHub Projects, Linear, Jira)
- Burndown charts
- Cumulative flow diagrams
- Cycle time tracking
