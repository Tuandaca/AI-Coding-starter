# Design Philosophy

## Core Beliefs

### 1. Design for Humans
- Empathy over aesthetics
- Accessibility is not optional
- Inclusive by default
- Respect user time and attention

### 2. Clarity Over Cleverness
- Obvious wins over novel
- Consistent patterns reduce cognitive load
- Progressive disclosure for complexity
- Error prevention over error messages

### 3. Systems Over Screens
- Design systems, not pages
- Reusable components
- Token-based theming
- Cross-platform consistency

### 4. Iterate with Evidence
- Data-informed, not data-driven
- Qualitative + quantitative
- Test with real users
- Measure what matters

## Design Principles

### Visual Hierarchy
- Size, weight, color, spacing
- One primary action per screen
- Group related elements
- Use negative space intentionally

### Typography
- Readable at all sizes
- Meaningful scale (modular scale)
- Line length 45-75 characters
- Sufficient contrast (WCAG AA+)

### Color
- Semantic color system
- Accessible combinations
- Dark mode considered early
- Color not sole information carrier

### Motion
- Purposeful, not decorative
- 150-300ms transitions
- Respect prefers-reduced-motion
- Communicate state changes

## Process

### Discovery
- Understand problem before solving
- Stakeholder alignment
- User research (qual + quant)
- Competitive analysis

### Definition
- Clear problem statement
- Success metrics defined
- Scope boundaries
- Technical constraints

### Design
- Low-fi exploration
- High-fi for validation
- Design system compliance
- Developer handoff specs

### Delivery
- Design QA in CI
- Accessibility audit
- Performance budgets
- Post-launch measurement
