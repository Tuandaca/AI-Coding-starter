# UI/UX Pro Max Guidelines

## Core Principles

1. **Clarity First** - Every element should have a clear purpose
2. **Consistency** - Patterns repeat predictably across the product
3. **Feedback** - Users always know what's happening
4. **Efficiency** - Common tasks require minimal effort
5. **Accessibility** - Usable by everyone, including those with disabilities

## Layout Patterns

- **Grid Systems**: 12-column responsive grid
- **Container Widths**: 640px, 768px, 1024px, 1280px, 1536px
- **Spacing Rhythm**: 8px base unit throughout
- **Visual Hierarchy**: Size, color, weight, spacing

## Component Patterns

### Buttons
- Primary: High emphasis actions
- Secondary: Medium emphasis
- Ghost: Low emphasis
- Destructive: Dangerous actions

### Forms
- Labels always visible
- Inline validation
- Helpful error messages
- Logical tab order

### Navigation
- Clear current location indicator
- Consistent placement
- Keyboard accessible
- Mobile-responsive patterns

## Motion

- Duration: 150-300ms for UI transitions
- Easing: ease-out for entering, ease-in for exiting
- Respect `prefers-reduced-motion`
- Purposeful, not decorative
