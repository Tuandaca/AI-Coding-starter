# SEO Master Checklist

## Technical SEO

### Crawlability & Indexing
- [ ] Robots.txt allows important pages
- [ ] XML sitemap submitted to Search Console
- [ ] Noindex on appropriate pages (thank you, admin, etc.)
- [ ] Canonical tags on all pages
- [ ] No orphan pages
- [ ] Clean URL structure (no parameters when possible)

### Performance
- [ ] Core Web Vitals passing
- [ ] Mobile-friendly test passing
- [ ] HTTPS everywhere
- [ ] No mixed content
- [ ] Fast server response (TTFB < 600ms)

### Structured Data
- [ ] Organization schema on homepage
- [ ] Product schema on product pages
- [ ] Article schema on blog posts
- [ ] BreadcrumbList on all pages
- [ ] FAQ schema where applicable
- [ ] Valid JSON-LD (tested in Rich Results Test)

## On-Page SEO

### Content
- [ ] Unique, descriptive title tags (< 60 chars)
- [ ] Compelling meta descriptions (< 160 chars)
- [ ] H1 tag on every page (one per page)
- [ ] Logical heading hierarchy (H1 > H2 > H3)
- [ ] Target keyword in first 100 words
- [ ] Image alt text descriptive and keyword-relevant
- [ ] Internal links to/from relevant pages

### User Experience
- [ ] Clear navigation and site structure
- [ ] Breadcrumbs on deep pages
- [ ] Search functionality for large sites
- [ ] 404 page with helpful links
- [ ] Fast, intuitive mobile experience

## Off-Page & Authority

- [ ] Quality backlink profile
- [ ] Brand mentions monitoring
- [ ] Local SEO (if applicable): GMB, citations, reviews
- [ ] Social signals integration
- [ ] Disavow toxic links if needed

## Monitoring

- [ ] Search Console: weekly check for errors
- [ ] Rank tracking for target keywords
- [ ] Organic traffic trends (GA4)
- [ ] Index coverage report
- [ ] Manual actions check
